# Manual Software Quality Assurance Portfolio

Welcome to my software testing portfolio! This repository showcases my practical skills in manual quality assurance, strategic test planning, rigorous test case design, and end-to-end defect tracking. 

Having completed comprehensive manual QA training with a **core competency rating of 87%**, I designed this project to execute full-lifecycle validation on a major, high-traffic e-commerce ecosystem (Temu).

## 🛠️ Project Deliverables & Artifacts

This repository contains the complete end-to-end manual testing lifecycle:

*   **[📄 Master Test Plan](./ecommerce_qa_test_plan.pdf):** A comprehensive document detailing the strategic scope, cross-browser test environments, risk mitigation strategies, and system release criteria.
*   **[📊 Test Cases Matrix](./Special_QA_Testing_Portfolio.xlsx):** A master grid covering 50 distinct test scenarios encompassing Auth, Search, Cart, Checkout, Reviews, UI Localization, and Security paths.
*   **[📈 Executive Test Summary Report](./Special%20Project%20Test%20Summary%20Report.docx):** High-level testing execution metrics, overall pass/fail statistics, and formal release recommendations.
*   **[🪲 Defect & Bug Summary Report](./Special%20Project%20BUG%20SUMMARY%20REPORT.docx):** An analytical breakdown of discovered defects mapped by severity distribution and functional impact.

## 🔍 Core Testing Competencies Demonstrated

*   **Requirements Translation:** Architecting structured technical test scripts directly from e-commerce user journeys.
*   **Black-Box Test Design:** Utilizing Boundary Value Analysis (BVA), Equivalence Partitioning (EP), and negative testing paths.
*   **Defect Lifecycle Management:** Documenting highly actionable bug logs complete with environment baselines and replication protocols.
*   **Security & UI Integrity:** Auditing session boundaries, validation text boxes, and security filters against common edge-case vulnerabilities.
